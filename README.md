# 土特产网络销售系统

基于 Python Flask 和 SQLite 的土特产网络销售系统，支持消费者、商家、后台管理员三类角色。

## 运行环境

- Windows 10 及以上
- Python 3.10 及以上
- SQLite 随 Python 标准库提供

## 启动方法

在当前文件夹执行：

```powershell
python -m pip install -r requirements.txt
python app.py
```

浏览器打开：

```text
http://127.0.0.1:5000
```

如果 5000 端口被占用，可改用其他端口：

```powershell
$env:PORT=5001
python app.py
```

首次启动会自动创建 `sales.db` 数据库，并写入示例分类、商品和默认账号。

## 默认账号

| 角色 | 用户名 | 密码 |
| --- | --- | --- |
| 管理员 | admin | admin123 |
| 商家 | seller01 | seller123 |
| 消费者 | consumer01 | user123 |

消费者和商家也可以在注册页面自行创建账号。

## 功能说明

- 消费者：
  - 浏览已审核上架的商品。
  - 按关键词、分类查询商品。
  - 按销量、价格、库存、上架时间排序。
  - 加入购物车、直接修改数量并自动保存、删除购物车商品。
  - 提交订单并查看自己的订单。
- 商家：
  - 注册并登录商家账号。
  - 提交新增商品申报。
  - 对自己的商品提交修改、上架、下架申报。
  - 查看申报状态和驳回理由。
  - 被驳回后可编辑原申请并重新提交。
  - 消费者提交订单后，商家可在商家订单页查看自己负责的商品。
  - 商家填写物流单号或配送说明申请发货，管理员批准后才正式发货。
- 管理员：
  - 审核商家申报，批准后商品数据生效。
  - 驳回申报时填写理由并反馈给商家。
  - 管理商品、分类、订单和用户。
  - 审批或驳回商家的发货申请。
  - 查看商品数量、订单金额、库存预警和热门商品统计图；库存剩余 20 件及以下时预警。

## 审批规则

商家提交的新增、上架、下架、改价格、改库存、改描述等商品变更不会直接影响消费者可见商品。只有管理员批准申报后，系统才会创建或更新正式商品数据；管理员驳回时必须填写理由，商家可根据理由修改原申请后再次提交。

同一商家的商品名称在正式商品表中保持唯一；商品已有待审核申报时不能重复提交其他变更，避免新增和修改审批相互冲突。

商品默认按产品类型分类，包括水果类、生鲜类、粮油类、肉禽蛋类、菌菇类、坚果干果类、茶饮类和调味干货类。


## 仓库说明

Python 课程项目，技术栈为 Python / Flask / SQLite / Jinja2 / Chart.js。包含消费者、商家与管理员三类流程；`schema.sql` 定义 8 张核心业务表。

仓库保留源代码、模板、样式、建表脚本与依赖清单。运行产生的 `sales.db`、缓存和课程报告不纳入版本管理；首次启动会初始化示例数据。

建议创建虚拟环境后运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

默认账号仅供本地演示。当前代码默认启用调试模式，包含开发用会话密钥，不能直接当作生产部署配置；对外部署前应设置环境变量 `SECRET_KEY`、`FLASK_DEBUG=0` 并更换演示凭据。销售图表引用外部 Chart.js CDN，图表首次加载需要网络。
